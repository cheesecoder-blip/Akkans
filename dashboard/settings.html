Insert API Key

An API key is needed to use the Generate and AI features. Don't have one?

Get API Key

To get an API key, visit this website: OpenAI API Keys

1. Sign up or login in that website.

2. Navigate to the API keys section.

3. In the upper right, click "Create new secret key".

4. Create a name for the secret key.

5. Set expiration to however you want.

6. Click "Create secret key".

7. Copy the text.

8. Then back to this website, go to Settings, then paste it to Insert API Key, and click confirm.
